# 青柠小站

> 记录个人技术实践的学习笔记

**访问网站：[qingning.co](https://qingning.co)**

这里积累个人技术实践、项目探索、好用工具、汉化记录与一路学习中的发现。不追求一开始就覆盖所有领域，而是把试过、想明白的事情慢慢记下来。

## 关于这个仓库

本仓库保存由 Hexo 生成、供 GitHub Pages 托管的**静态网页产物**，不是文章和主题的编辑入口。页面修改应从受维护的源码重新构建、检查，再发布到这里。

| 路径 | 用途 |
|---|---|
| `index.html`、年份目录 | 首页与文章页面 |
| `articles/`、`archives/`、`categories/`、`tags/` | 文章列表与索引 |
| `css/`、`js/`、`images/` | 页面样式、交互和图片 |
| `subscribe/`、`atom.xml` | 订阅入口与 Atom feed |
| `search.json`、`sitemap.xml`、`robots.txt` | 站内搜索与搜索引擎发现 |
| `404.html` | 自定义未找到页面 |
| `.github/workflows/static.yml` | GitHub Pages 静态发布流程 |

目录结构也是网站地址的一部分。请不要为整理目录移动生成页面，或把工作流替换成源码构建检查。下一次发布应保留工作流，并核对失效产物。

## 内容说明

文章是个人实践与学习记录，不保证适用于所有环境。项目和工具介绍尽量链接官方来源，说明实际尝试的部分与局限；引用和汉化素材应遵守各自的许可证或授权。

站点界面采用青柠配色与本地静态资源，不依赖独立的博客服务器。网站名称与仓库名称不必相同。
