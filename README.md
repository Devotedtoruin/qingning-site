# 青柠小站

**[访问 qingning.co](https://qingning.co)**

青柠小站，分享技术文章与实用经验。通过分类、标签和站内搜索，查找感兴趣的内容。

## 关于这个仓库

本仓库保存供 GitHub Pages 托管的静态网页产物。文章与主题从受维护的源码生成、检查后发布，不直接编辑此处的 HTML。

| 路径 | 用途 |
|---|---|
| `index.html`、`posts/` | 首页与文章页面 |
| `articles/`、`archives/`、`categories/`、`tags/` | 文章列表与索引 |
| `css/`、`js/`、`images/` | 页面样式、交互和图片 |
| `subscribe/`、`atom.xml` | 订阅入口与 Atom feed |
| `search.json`、`sitemap.xml`、`robots.txt` | 站内搜索与搜索引擎发现 |
| `404.html` | 未找到页面与已知旧链接恢复入口 |
| `.github/workflows/static.yml` | GitHub Pages 发布流程 |

文章采用不带日期的路径；页面上的文章日期保持显示。请勿手工搬动生成页面，或覆盖发布工作流。

引用、截图和其他素材遵守各自的许可证或授权。内容是否适用需结合具体版本与环境判断。
