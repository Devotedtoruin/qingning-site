house-plan-designer：把户型图变成可交互 2D/3D 装修设计网页的 Skill

2026年10月6日 · 项目 · 约 5 分钟阅读

更新于 2026年10月10日

把户型图变成可交互 2D/3D 装修设计网页的 Skill。

#AI#开源项目#Agent

本页目录

    house-plan-designer 由 ZWD11 维护，是一个面向 Agent 的装修设计 Skill。给它一张带尺寸的户型图、一份 CAD 导出的 PDF 或 DXF，再补一句装修要求，它会先量墙、识别门窗和房间，最后生成一个双击就能打开的单文件 HTML 设计器。设计数据、3D 模型和交互都在这个文件里，不依赖外部服务。

    从读图到生成，中间有自查

    输入路线分两类。彩色户型图、截图或扫描件走 OpenCV 提墙，再按图上的尺寸标注把像素换算成毫米；CAD 导出的矢量 PDF 和 DXF 则直接读图元坐标，墙厚、洞口和标注数字来自原始数据。遇到一页并排好几层的别墅图，脚本会按楼层切开，对齐各层坐标，输出整栋楼初稿和楼梯、电梯、开洞候选。

    读完只是初稿。build.py 生成网页后，check.mjs 会用无头浏览器检查房间是否闭合、有没有悬空墙、门窗是否丢失，并把结果半透明叠回原图，算外围尺寸和每个房间的开间进深。对不上就继续改，直到墙墙重合。交付前还有 qa.mjs，会把 2D 编辑、属性面板、水电视图、导出、3D 漫游和智能中控逐项操作一遍。这些是仓库规定的流程，不代表每个户型都能一次通过。

    设计器里能做什么

    2D 层可以画墙、拆墙、改门窗，面积实时重算，支持十二种门窗和五种装修图层。家具库约一百八十件，橱柜、定制柜、浴室柜、淋浴房和中岛可以参数化调整，2D、3D、立面图和报价共用同一份数据。

    水电是它比较特别的一块：插座、照明、网线、冷热水和排水会按房间与回路自动排布，走地或走顶、管径、线径和坡度都有规则说明；五类管线可以分开查看、分开导出 DXF，另给回路表和材料清单。多层住宅还支持楼层切换、楼梯、挑空、电梯、车库和庭院。3D 侧有鸟瞰、第一人称漫游、720 度全景、按城市和时间计算的日照，以及可选的路径追踪出图；智能中控只是装修前预演，不连接真实设备。

    把仓库放进 Agent 的 skills 目录，以 Claude Code 为例：

    本机还需要 Chrome 或 Edge 供自查截图使用；找不到时用 CHROME_PATH 指向浏览器。之后把户型图和“客厅铺 800×800 灰色大板、主卧人字拼木地板、厨房做 L 形橱柜”这类要求一起交给 Agent，生成结果会附带识别说明，列出哪些尺寸来自标注、哪些是按图形量的、图纸自身哪里矛盾。

    装修前做空间预演

    一套三室两卫的房子准备装修，先不改墙，只把家具、插座、灯位和橱柜方案摆进去。把开发商的彩色户型图交给 Agent，让它按图生成设计器；自己检查叠图是否对齐、门是否被家具挡住、厨房水槽是否在窗下。方案确定后导出彩平图给家人看，再把水电点位图和 DXF 交给电工沟通。需要比较两版方案时，用设计器内的多方案管理，而不是复制多个网页。

    和酷家乐、CAD 的差别

    酷家乐这类在线工具强在素材库、渲染和协作，CAD 强在施工图精度；house-plan-designer 的卖点是本地单文件、自然语言驱动和可修改的源数据。它导出的 DXF 是标准线、填充、标注、编组和图块，不含天正自定义实体；在 CAD 里拉墙不会带动相接墙体，要改仍回设计器改。它也不适合替代施工图和专业设计。

    限制与适合的人

    带尺寸标注的图效果最好，黑底截图和只画双线的墙需要 Agent 按标注手写，轮次更多；纯线稿、拍歪的照片和没有任何尺寸的图，识别初稿会很差。承重墙按颜色或厚度判断，最终要以物业结构图为准。存档保存在浏览器本地，换电脑或发给别人要用“导出分享文件”。水电排布是规划建议，正式施工前仍要按现行规范和专业人员核算。

    适合准备装修、愿意自己校对尺寸和方案的人，也适合想把户型展示做成交互网页的开发者。需要施工图级精度、复杂异形结构或多人实时协作时，应该找专业设计软件和设计师。
