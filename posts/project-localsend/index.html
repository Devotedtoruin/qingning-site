LocalSend：跨平台局域网文件传输工具

2026年9月4日 · 项目 · 约 5 分钟阅读

更新于 2026年9月8日

跨平台局域网文件传输工具。

#开源项目#效率工具

本页目录

    LocalSend 是一个跨平台的局域网文件传输工具，用 Flutter/Dart 编写，Apache-2.0 许可，官网 localsend.org。它解决的是“同一间屋子里，Windows 电脑和 iPhone 之间传一个文件”这种小事：不需要账号、不上传云端、传的是原文件，两台设备在同一网络里就能直接发送文件和文字消息。项目 2022 年 12 月创建，覆盖 Windows、macOS、Linux、Android、iOS 和 Fire OS。本文按官方 README 整理，未在本机完整实测；平台版本和网络配置以当前文档为准。

    局域网直传的工作方式

    每台设备运行一个本地服务，通过 REST API 互相发现和传输，数据走 HTTPS，TLS 证书在每台设备上即时生成。因为不依赖第三方服务器，传输速度取决于局域网带宽和 Wi-Fi 质量，文件也不会经过公网。

    首次使用时系统会询问是否允许本地网络访问。接收方可以设置设备名、可见性和是否需要确认；发送方选择设备后开始传输，进度和结果都在本地显示。README 还提到便携模式：在可执行文件旁放一个空的 settings.json，配置就写在这个文件里，适合放在 U 盘里带走。启动参数 --hidden 可以让应用只留在托盘。

    跨平台与安装

    README 建议从应用商店或包管理器安装，因为 LocalSend 没有自动更新。Windows 有 Winget、Scoop、Chocolatey、EXE 安装包和便携 ZIP；macOS 有 App Store、Homebrew 和 DMG；Linux 有 Flathub、Snap、AUR、DEB、AppImage 等；Android 有 Play Store、F-Droid 和 APK；iOS 走 App Store。

    最低版本要求：Android 7.0、iOS 13.0、macOS 11 Big Sur、Windows 10。Linux 需要 xdg-desktop-portal 及对应桌面环境的实现。老系统只能用旧版本，README 列出了最后支持的版本号。Windows 二进制有代码签名；macOS 和 iOS 走系统商店或安装包，升级节奏跟平台走。

    典型场景

    摄影师在工作室用 Windows 台式机修图，客户到现场后用 iPhone 选片。两台设备连同一个 Wi-Fi，打开 LocalSend，选中 2 GB 的原图文件夹发送，数据走本地网络，不经过任何云盘，也不需要数据线或安装 iTunes。传完后关闭应用即可，不留账号和云端副本。临时给同事发一段报错日志，也可以直接用文字消息，不必先存成文件。

    和 AirDrop、聊天工具传文件的差别

    AirDrop 只在 Apple 设备之间好用，跨到 Windows 或 Android 就断了；微信、QQ 的文件传输助手会经过云端、有大小限制，图片还可能被压缩。LocalSend 的优势是跨平台和原文件传输，缺点是需要同一局域网。Snapdrop、PairDrop 这类浏览器方案不用安装，但大文件传输更依赖浏览器和网络状态，稳定性与原生客户端不是一回事。

    网络限制与排障

    最常见的问题是设备互相看不见：路由器开了 AP 隔离（访客网络常见）、Windows 把网络识别为“公用”、macOS 或 iOS 没给本地网络权限，或者 VPN 拦截了局域网流量。README 给出的排查顺序是关闭 AP 隔离、把网络设为专用、检查本地网络权限、放行 VPN 的局域网流量，最后用 IP 直连。防火墙需要放行 TCP 和 UDP 的 53317 端口，Linux 上可以用 ufw 或 firewall-cmd 配置。

    速度慢时优先用 5 GHz Wi-Fi；Android 接收端有已知的速度问题，README 链接到上游 issue。传输本身是加密的，关闭加密能提速，但要清楚这意味着同一网络中的其他人可能截获内容。LocalSend 也没有集中管理、审计或跨公网中继，企业环境要另外评估。

    适合谁

    适合经常在 Windows、macOS、Android、iOS 之间倒腾照片、视频和文档的个人和小团队；也适合不想把内部文件放到云盘的公司。需要跨公网传输、集中审计或企业设备管理的组织，应该用专门的文件交换平台。
