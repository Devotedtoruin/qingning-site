mcp-for-blender：用自然语言控制 Blender 的社区 MCP 插件

2026年9月8日 · 项目 · 约 5 分钟阅读

更新于 2026年9月12日

用自然语言控制 Blender 的社区 MCP 插件。

#开源项目#AI#视频

本页目录

    mcp-for-blender 由 ahujasid 维护，前身是 blender-mcp，PyPI 包名已改为 mcp-for-blender。它把 Blender 变成一个 MCP 服务器：任何支持 Model Context Protocol 的客户端都能连上来，用自然语言建模、改材质、布光、摆相机、渲染。README 明确声明这是第三方集成，与 Blender Foundation 无关。

    两件东西：MCP 服务与 Blender 插件

    系统由两部分组成：一个 Python MCP 服务器负责和客户端说话，一个 Blender 插件在 Blender 内部开 socket 服务器执行命令。两边通过 JSON 消息通信，命令带 type 和可选参数，返回 status 与结果。安装时两者都要到位，只装 Python 包或只开插件都连不上。

    一条命令装齐

    官方提供一键安装脚本，会检测本机的 Claude Desktop、Claude Code、Codex、Cursor、VS Code、Windsurf、OpenCode 等客户端，让你选择要配置哪些，再安装并启用 Blender 插件：

    Windows 用 PowerShell 的 irm ... | iex，或者先 winget install --id=astral-sh.uv -e，再执行 uvx mcp-for-blender setup。手工配置也不复杂：

    然后在 Blender 的 Edit → Preferences → Add-ons 里启用 Interface: MCP for Blender。3D 视图按 N 打开侧栏，找到 MCP for Blender 标签，勾选要用的能力，点 Connect to Claude。插件随 Blender 启动而开服务器，同一时间只应运行一个 MCP 服务实例。客户端从 GUI 启动时不会继承终端 PATH，如果报 spawn uvx ENOENT，用 which uvx 或 where uvx 查到的绝对路径替换命令，改完配置要完全退出并重启客户端。

    九个工具里挑几个说

    execute_blender_code 让模型直接在你的 Blender 里跑 Python，这是能力的来源，也是风险所在。只想让模型执行一段现成脚本时，走到这一步就够了，其余工具可以按需开启。look 负责视觉校验，可以从视口、相机、自动取景的多角度组合或动画帧序列截图，支持 solid、material、rendered、wireframe、xray 等显示方式。get_scene_info 返回紧凑的场景摘要，每行一个对象，可按位置、材质、拓扑、权重等字段筛选。generate_3d 一次调用完成生成并导入，接的是 Tripo、Hunyuan3D、Hyper3D Rodin 或 Meshy。search_assets 与 import_asset 覆盖 Poly Haven 的 HDRI、贴图和模型，Sketchfab 模型，以及 Poly Pizza 的低模。

    资产导入会保留来源信息：Poly Haven 全部是 CC0，导入后对象上会写入 polyhaven_id、作者、分辨率和许可证；Poly Pizza 约 69% 是 CC-BY，导入时会写入 polypizza_attribution，商用时要按许可证署名。

    一个布景流程

    让它“用阴天午后的 HDRI 打光，给墙面上锈金属贴图”：模型先搜索 Poly Haven，拿到候选缩略图，再导入 HDRI 和贴图并应用到指定对象，最后用 look 从相机视角检查。不满意就继续调材质或换角度，整个过程留在 Blender 会话里，不需要手工找资产再拖进节点编辑器。做占位场景、快速概念图、批量改材质时，这种闭环比手动操作快。

    与 CLI-Anything 的 Blender CLI 对比

    CLI-Anything 也能为 Blender 生成命令行，但那条路面向批处理和无人值守：命令写在脚本里，适合 CI、批量渲染和可重复的资产生成。mcp-for-blender 面向实时会话，模型在打开着的 Blender 里边看边改。两者的共同点是都调用真实 Blender，而不是另写一个简化渲染器；选择取决于你要“对话式建模”还是“流水线执行”。

    限制与安全

    execute_blender_code 能运行任意 Python，README 用大写提醒先在 Blender 里保存工作，生产环境谨慎使用。复杂操作要拆成小步骤，超时通常意味着该简化请求。Poly Haven 资产在 Blender 主线程下载，下载期间界面会卡住，靠近镜头的资产再用 2k 以上分辨率。Poly Pizza 的 CDN 会拦截数据中心、VPN 和云主机 IP，失败时与 API Key 无关。遥测默认只收最小匿名使用记录，提示词、生成代码、截图和场景数据在未勾选同意前不会上传，可用 DISABLE_TELEMETRY=true 全部关闭。本文按官方 README 与仓库元数据整理，未在本机完整实测。

    适合谁

    适合需要快速做 3D 占位、概念场景、批量材质调整的创作者，以及想把 Blender 接进 agent 工作流的开发者。需要严格拓扑、精细绑定和可复现工业级输出的项目，仍应由人工主导，模型只做辅助。
