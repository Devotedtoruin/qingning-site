Filee：拖拽即转的离线文件转换器

2026年9月29日 · 项目 · 约 5 分钟阅读

更新于 2026年10月3日

拖拽即转的离线文件转换器。

#开源项目#效率工具

本页目录

    Filee 是 KnifeLemon（Myeonggu Kim）开发的开源文件转换器，用 C# 和 Avalonia 编写，MIT 许可。它把“选文件、选格式、点转换”压缩成一个拖拽动作：按住 Ctrl（macOS 上是 Option），把文件拖到光标处弹出的格式环上松手，转换在本地完成，结果保存在原文件旁边。项目 2026 年 9 月创建，官网 filee.sh，Windows、Linux 和 macOS 预览版都已提供。本文按官方 README 整理，未在本机完整实测；格式支持和安装步骤以当前版本为准。

    光标处的格式环

    Filee 没有传统的主窗口流程。按住修饰键拖动文件时，光标位置会出现一个圆环，只显示与当前文件类型匹配的目标格式；把文件丢到某个格式上，进度环走完，新文件就出现在同一目录。按 Tab 或滚动滚轮可以把圆环翻到背面，看到不常用的格式和工具。

    每种文件类型有独立的工具栏，可以拖拽排列，并保存预设：图片的质量、尺寸、DPI，PDF 的页码和压缩，视频音频的编码参数，输出目录和文件名规则。转换前还能裁切图片，支持多文件并行，自动寻找多步转换路径，例如 HWP → HWPX → DOCX。监视文件夹会持续转换落入其中的新文件，最近的转换记录带缩略图，可以直接打开结果或换一个应用打开。

    格式与可选引擎

    README 按类别列出了很长的支持范围：图片（含 HEIC、RAW、PSD、DICOM）、矢量图、PDF、Word、Excel、PowerPoint、HWP/HWPX、电子书、视频、音频、字幕、压缩包、CAD、字体、JSON/YAML/TOML、3D 模型和地理数据。按 README 的说法有两百多种，具体到某个冷门格式，仍要看当前版本的格式表。

    大部分格式开箱可用，不依赖 Office、Hancom Office 或 LibreOffice。需要额外引擎的格式会在第一次使用时才下载：Ghostscript 处理 EPS/PS，LibreOffice 处理部分旧文档格式，Pandoc 处理 Markdown 等文本格式，calibre 处理 MOBI/AZW3，FFmpeg 处理视频音频。安装包因此不必一开始就很大，但离线环境要提前准备好这些引擎。

    隐私

    README 的隐私政策写得很具体：转换全部在本机完成，不上传文件；不收集使用数据，不发遥测。联网只发生在三种情况：启动后和每隔几小时向 GitHub 查询新版本（可在设置里关闭）、下载你选择的转换引擎和 OCR 语言包、点击链接时打开浏览器。对需要处理合同、证件或内部文档的人来说，这比在线转换器少了一层数据外泄风险。

    典型场景

    行政同事收到一份 HWP 格式的韩国合作方文档，需要转成 DOCX 再编辑。把文件拖到 Filee 的格式环上，等几秒得到 DOCX，用 Word 打开检查表格和字体。全程没有把文件上传到任何网站，也不需要在电脑上安装 Hancom Office。转换完的 DOCX 就放在原文件旁边，命名和目录都能在预设里固定。

    和在线转换器的差别

    iLovePDF、CloudConvert 这类在线工具胜在不用安装、格式覆盖广，但文件要离开本机，免费版还有大小和次数限制。Filee 把转换放回本地，代价是安装包、可选引擎和平台适配。与 LibreOffice 的“打开再另存为”相比，Filee 的路径更短，适合重复的批量任务，但不提供 Office 套件的编辑能力。

    限制

    macOS 版仍是预览，安装包未公证，首次启动要在系统设置里允许；Linux 上的拖拽手势依赖 X11，Wayland 只能用放置区或文件管理器右键菜单。复杂字体、版式和宏在转换后可能失真，重要文档要人工复核。部分格式需要额外引擎，首次使用要联网下载。Windows 10 长期未更新的机器可能因 CET 保护与 .NET 冲突而无法启动，README 给出更新系统或对 Filee 单独关闭 UserShadowStack 的两种处理方式。它也不是排版或印刷工具，不能替代专业出版流程。

    适合谁

    适合经常在多种文档格式之间转换、又在意文件隐私的普通用户和办公室团队；也适合需要批量转换或把转换接进脚本的开发者。需要印刷级排版、复杂宏兼容或企业集中管理的场景，应使用专业文档工具。
