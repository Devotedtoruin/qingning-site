女娲.skill：蒸馏一个人的思维方式、决策启发式和表达 DNA 的 Skill

2026年9月15日 · 项目 · 约 5 分钟阅读

更新于 2026年9月19日

蒸馏一个人的思维方式、决策启发式和表达 DNA 的 Skill。

#AI#开源项目#Agent

本页目录

    女娲.skill 是花叔（alchaincyf）开源的 Agent Skill，仓库为 alchaincyf/nuwa-skill。输入一个公开人物的名字，它会去收集著作、播客、访谈、社交媒体、批评者视角、决策记录和人生时间线，提炼成可调用的思维模型、决策启发式和表达风格。README 反复强调：这不是角色扮演，是提取“认知操作系统”。按官方 README 整理，未在本机完整实测。

    蒸馏的五层

    README 把蒸馏对象分成五层：怎么说话，指表达 DNA，包括语气、节奏和用词偏好；怎么想，指心智模型和认知框架；怎么判断，指决策启发式；什么不做，指反模式和价值观底线；知道局限，指诚实边界。

    工作习惯可以靠流程文档传递，但让芒格和马斯克面对同一个问题给出不同判断的，是认知框架。这个 Skill 想提取的正是后者，而不是几句名言或口头禅。

    四步工作流

    第一步是六路并行采集：著作、播客和访谈、社交媒体、批评者视角、决策记录、人生时间线，六个 Agent 同时跑，各自存档。

    第二步是三重验证。一个观点要被收录为心智模型，必须跨两个以上领域出现过，能用来推断此人对新问题的立场，并且不是所有聪明人都会这么想。三条都过才收录，避免把通用常识包装成个人洞见。

    第三步是构建 Skill：写入 3–7 个心智模型、5–10 条决策启发式、表达 DNA、价值观与反模式，以及明确的诚实边界，最终形成 SKILL.md。

    第四步是质量验证：拿三个此人公开回答过的问题测试方向是否一致，再拿一个他没讨论过的问题测试 Skill 是否表现出适度不确定，而不是斩钉截铁。

    一个决策场景

    同时想做自媒体、写书和独立开发，精力不够。让 Skill 以 Naval 的框架分析，它应该围绕“欲望即合同”和特定知识来拆，而不是复读几句关于杠杆的话；换成芒格，则可能先问反过来会怎样、哪些事会直接导致失败。价值在于得到一个有结构的第二意见，而不是获得此人的真实表态。

    用于团队知识沉淀时，更适合蒸馏公开的方法论，而不是未经同意拆解身边同事的私人材料。

    与角色扮演、同事.skill 的差别

    普通的角色扮演提示只写“你是某某”，然后模仿语气；女娲要求材料跨领域、可预测、非共识，才允许一个模型进入 Skill。同事.skill 蒸馏的是离职同事的工作习惯和流程知识，女娲瞄准的是公开人物的认知框架，两者都是蒸馏，对象不同。

    README 还给出了一套保真度评分卡，声称 15 个官方 Skill 通过双 Agent 盲测并全部达到 A 级。这是项目自建的方法和自报结果，能说明作者做了验证，但不能当作独立学术验证。

    诚实边界

    README 自己列了三条：蒸馏不了直觉，框架能提取，灵感不能；捕捉不了突变，Skill 是截止调研时间的快照；公开表达不等于真实想法，只能基于公开信息。

    使用者的边界还要再加几条。不要用它冒充本人发言，也不要用它替本人做未经授权的决策。公开材料也有版权和使用条件，引用原话要能回到来源。生成结果可能语气很确定但事实错误，最好拿本人公开回答过的问题先校准。
