Fincept Terminal：开源金融终端

2026年9月6日 · 项目 · 约 5 分钟阅读

更新于 2026年9月10日

开源金融终端，提供市场分析、投资研究和经济数据。

#开源项目#效率工具

本页目录

    Fincept Terminal 是 Fincept Corporation 开发的桌面金融终端，用 C++20 和 Qt6 编写，内嵌 Python 3.11 做分析，打包成单一二进制，不依赖 Electron 或浏览器运行时。仓库里的开源版采用 AGPL-3.0-or-later，面向学习、个人使用和学术研究；面向机构的闭源 Enterprise 版另行销售。

    一个不基于 Electron 的金融终端

    金融数据终端长期是高价、封闭的代名词。另一条路是用 Python 把数据源、Notebook 和图表拼起来，灵活但每换一个数据集就要重写胶水代码。Fincept 想做的是中间形态：原生桌面应用，内置行情、宏观数据、分析模型、AI Agent 和交易接口，装完就能在一个界面里完成研究流程。

    数据、分析与 AI 的三块拼图

    分析侧包含 DCF、组合优化、VaR/Sharpe、衍生品定价、固定收益和另类资产，另有一套 18 模块的 QuantLib 套件。AI 侧提供 37 个面向交易者、投资者、经济和地缘政治的 Agent，模型 Key 自带，支持 OpenAI、Anthropic、Gemini、Groq、DeepSeek、OpenRouter 和 Ollama。

    数据侧列出 100 多个连接器，覆盖 FRED、IMF、World Bank、DBnomics、AkShare、Polygon、Kraken、Yahoo Finance 和政府公开 API。交易侧有加密和股票行情、模拟交易引擎，以及 16 个券商集成。自动化侧提供可视化节点编辑器、MCP 工具和 AI Quant Lab，后者用于机器学习、因子发现和强化学习实验。

    独立研究者的工作日

    早上先用 FRED 和 World Bank 的连接器拉一组宏观数据，在终端里画趋势；下午对一家公司做 DCF，把关键假设存成不同情景；收盘前用模拟交易引擎试一套调仓规则。遇到不熟悉的指标，可以让经济或地缘政治 Agent 解释背景，再回到原始数据核对。节点编辑器适合把重复的取数、计算和图表步骤串起来，不必每次重写脚本。

    与 Bloomberg、Notebook 的分工

    Bloomberg 这类商业终端卖的是实时行情、机构级数据、合规和支持，价格也按机构预算设计；README 直接把两者的席位成本放在一起对照。Fincept 的开源版不承诺同等级的数据覆盖和实时性，优势是代码可见、可改、可自建研究流程。和纯 Notebook 方案相比，终端把连接器、图表、组合和交易接口预先接好，代价是灵活性和可编程深度不如自己写 Python。

    AGPL 与“免费版”的真实成本

    AGPL-3.0 是强 copyleft，不是宽松许可：分发修改后的版本，或把它作为服务提供给他人访问，都要按同一许可公开改动。个人使用、不对外分发，不产生这些义务。公司若要用于商业部署或对外提供服务，README 指向 Enterprise；继续使用开源版，则要履行 AGPL 的公开义务。

    免费指的是代码许可，不是使用成本。数据源有自己的授权和 API 额度，模型按 token 计费，README 明确说开源版的真实成本是自己的数据和 LLM 账单。开源仓库每月发布一次，团队日常开发在 Enterprise，修复节奏和功能完整性会有差距；macOS 只提供 Apple Silicon 包，Intel Mac 用户要自己构建。

    谁该用开源版

    适合学生、个人投资者、学术研究者和需要自建研究环境的独立分析师。需要机构级实时行情、合规审计、SLA 或多人权限管理的团队，应评估 Enterprise，而不是指望开源版补齐这些能力。终端展示的数据和分析不构成投资建议，交易前仍要独立核对。
