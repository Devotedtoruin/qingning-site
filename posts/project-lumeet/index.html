Lumeet-V1：开源 AI 角色视频通话应用

2026年10月10日 · 项目 · 约 5 分钟阅读

更新于 2026年10月14日

开源 AI 角色视频通话应用。

#开源项目#AI

本页目录

    Lumeet-V1 把一张角色图片、几组第三方 API Key 和一台手机拼成一次实时视频通话：用户说话，模型生成回复，语音合成后由 Vivix 驱动嘴型和表情，再经 TRTC 推回屏幕。README 署名作者是抖音用户 @小香菇，许可证为 PolyForm Noncommercial 1.0.0，仅供个人自用、禁止商用，并明确禁止未成年人使用。

    通话链路由哪些部分组成

    一次通话要经过四段：Whisper 一类语音识别把用户的话转成文字（可选，不填只能打字）；模型生成回复，可以直连 OpenAI 兼容 API，也可以走 MCP 桥接；ElevenLabs、MOSS 或 MiniMax 把文字合成语音；Vivix 负责角色对嘴与表情，TRTC 负责实时传输。角色图片必须是 Vivix 服务器可访问的公开 HTTPS 地址，这是启动前最容易卡住的一步；用 MCP 桥接时可以直接从设备上传，由桥接器生成可访问网址，不必先找图床。

    两种模型接入方式

    直接 API 模式在设置页填写 Base URL、API Key 和 Model，适用于 OpenAI、DeepSeek、Groq、OpenRouter 等兼容端点。MCP 桥接模式面向只有订阅账号、没有模型 Key 的场景：先在 mcp-relay 目录执行 bash deploy.sh 部署到自己的 Cloudflare 账号，再把输出的 MCP 网址加入 Claude Code 或 Codex：

    通话前对 AI 说“进入视讯通话模式”，AI 通过 call_wait_message 等待输入、用 call_reply 回复。电脑上的 Claude Code 或 Codex 必须全程开着，桥接只保留最近 100 条消息。安卓端可直接安装仓库提供的 debug APK；自行打包需要 Node.js 20+、JDK 21 和 Android SDK platform 36，执行 npm install 后运行 npm run android:apk。

    第一次配置可以按这个顺序走：安装 APK（手机要允许未知来源应用）、勾选使用声明、打开右上角 ⋯ 进入设置、逐项填入 Vivix Key 与模型信息、按“测试连线”确认每一项都是 OK，再回主画面按“开始视讯”并授予相机与麦克风权限。MCP 桥接部署需要一次免费 Cloudflare 账号。语音合成不填 ElevenLabs 时会使用 Vivix 内置声音；大陆用户可选 MOSS 或 MiniMax，MiniMax 的大陆版与国际版 Key 不通用，选择时要对应账号版本。网页版要先部署桥接器，用 Safari 打开桥接网址后“加入主画面”，GitHub Pages 和本地服务器都不行，因为 Vivix 不允许浏览器直连。

    一个典型场景

    一个常见用法是给自己做一个原创角色：准备有使用权的立绘和授权声音，接 DeepSeek 或 Claude 的 API，每晚在手机上通话十分钟练习表达；如果只有订阅账号，则把 MCP 桥接接到电脑上的 Claude Code，并让电脑保持开机。通话结束关闭应用，Key 与桥接密码不要留在聊天记录或截图里。

    隐私、同意与退出

    API Key 只保存在手机或浏览器本地，安卓端关闭了系统自动备份，代码不记录、不上传分析数据；网页版的 Key 存在 localStorage，遭遇 XSS 时可能外泄。使用前应确认角色图片、声音和形象的使用授权，尤其是克隆真人声音或使用他人肖像时，需要本人明确同意；首次启动的使用声明要手动勾选，未成年人不应绕过。MCP 桥接密码相当于通话入口，不要与其他服务共用；不再使用时可以在 Cloudflare 面板删除对应 Worker。结束使用可以在设置里清空 Key、停止并删除桥接、卸载应用；对话记忆只存在桥接进程内存中，重启即消失。情感陪伴类应用容易产生依赖，建议给自己设定使用时段，并保留线下社交。

    与托管角色聊天应用的区别

    Character.AI、星野一类产品提供现成角色、托管模型和开箱即用的体验，代价是角色、对话与计费都经过平台。Lumeet 不提供角色库，需要自己准备图片、声音和模型 Key，换来的是模型选择、Key 存放和桥接链路都由自己掌握。前者更像内容平台，角色由平台提供；后者把角色图片、声音和模型都当成自己配置的资源。更准确地说，这是一条自己搭建的数字人通话管线，而不是一个消费级社交产品。

    限制与适合的人

    目前只有 debug 签名版 APK，换正式签名时需要先卸载旧版；角色说话时不收音，想插话要按“打断”；网页版必须依赖桥接器，GitHub Pages 和本地静态服务器都不能直接跑。按官方 README 整理，未在本机完整实测，通话延迟与各语音服务的实际效果取决于所选的第三方服务。适合愿意自己管理 API Key、能接受调试版应用、对角色形象和声音拥有使用权的开发者；期待稳定商用服务或不愿配置多个第三方账号的人不适合。
